# Security policy

settings-codegen is a development tool: it runs at build time and generates PHP classes.

## Supported versions

Only the latest `0.x` release gets fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately via
[GitHub private vulnerability reporting](https://github.com/tikhomirov/settings-codegen/security/advisories/new)
or by email to alex@rwsite.ru. You will get an answer within a week.
